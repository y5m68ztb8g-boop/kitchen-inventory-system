# 手机端全屏搜索设计

## 目标

优化首页搜索在手机上的显示和连续使用体验。手机用户进入搜索后只需要查看搜索输入与结果，不再同时显示区域、AI 录入和库存金额模块。桌面端维持现有首页内展开方式。

## 打开与关闭

手机端点击首页“搜索”模块后，在当前页面打开全屏搜索层，不建立新的路由，也不丢失首页状态。

全屏搜索层顶部固定显示搜索图标、标题和一个清晰的 `×` 关闭按钮。用户点击 `×`，或使用浏览器/设备返回操作时，退出搜索并返回首页。手机端不使用“点击空白区域关闭”，避免滚动和选择结果时误触退出。

关闭搜索层后清空库存搜索词、历史采购搜索词、当前搜索模式、搜索结果和复制成功提示。下次打开时显示干净的搜索界面。

## 连续搜索

搜索层保留两组上下排列的输入：

- 历史采购 / Invoice / Code
- 库存产品

用户编辑哪一行，结果就切换到对应搜索模式。删除当前关键词只清空当前结果，不关闭搜索层，也不自动返回首页，用户可以立即输入下一个关键词。

## 结果布局

结果使用手机屏幕可用宽度并在搜索栏下方纵向滚动。搜索标题栏和输入区域保持可见或容易返回顶部，不让结果遮挡关闭按钮。

库存结果继续显示仓库标签、位置、库存数量和等比例库房示意图。库房实际结构比例不改变，只缩小卡片外围留白、间距和手机字号。

历史采购结果继续显示供应商、产品编码、包装、价格、采购次数和日期。手机端产品编码保持横向可读，复制及打开 Brakes 按钮放到下一行或独立操作区，不能再把编码挤成逐字竖排。

## 桌面端

宽于手机断点的页面保持现有行为：搜索模块在首页网格内展开，点击搜索结果之外的区域可以收起结果。全屏搜索层和固定关闭栏只应用于手机布局。

## 可访问性

关闭按钮使用图标并提供中文可访问名称“关闭搜索”。打开后焦点进入适合的搜索输入；关闭后焦点返回首页“搜索”按钮。搜索层具有明确的对话框或区域语义，按 `Escape` 也能关闭。

## 测试

自动化测试覆盖：

- 手机端点击搜索后只显示全屏搜索界面，不显示其他首页模块。
- 两个搜索输入和关闭按钮完整显示，无水平溢出或文字裁切。
- 清空搜索词后搜索层保持打开。
- 连续搜索第二个关键词不需要重新打开搜索。
- 点击关闭、按 `Escape` 或浏览器返回可退出并恢复首页。
- 关闭后再次打开时搜索词和结果已清空。
- 历史采购产品编码横向显示，操作按钮不挤压编码。
- 库存示意图保持既有结构比例和高亮位置。
- 桌面端现有搜索展开与点外部收起行为不变。
